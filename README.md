# 好多鹈鹕 🦤 So Many Pelicans

> 不许备考，专治背题。
> *No prep allowed — memorized answers won't save you.*

🔗 在线体验 / Live demo: https://somanypelicans.pages.dev/

---

## 这是什么？ / What is this?

一个**随机 AI 测试题生成器**。每一道题都是在你的浏览器里**现场随机生成**的——数字、名字、条件，每次都不一样。

A **random AI quiz generator**. Every question is **generated live in your browser** — numbers, names, and conditions are different each time.

为什么要这样？因为公开题库有个死结：**题目一旦公开，就可能被拿去训练 AI**。你再拿原题去考它，考的是记忆力，不是推理能力。

Why bother? Public question banks have a fatal flaw: **once published, they can end up in AI training data**. Testing a model with those questions measures memorization, not reasoning.

好多鹈鹕把这条路堵死了：**具体这一道题，AI 不可能见过**。做对了，只能是现场推出来的。

So Many Pelicans closes that loophole: **this exact question is one the AI has never seen**. If it gets it right, it had to reason it out on the spot.

## 怎么玩？ / How to play

1. 打开网站，选类别、选难度，点"换一道"。 / Open the site, pick a category and difficulty, hit "new question".
2. 把题目复制，发给任意 AI 模型。 / Copy the question and send it to any AI model.
3. 看它是真推理，还是在背答案。 / See whether it truly reasons or just recites.

每道题带一个 6 位随机实例 ID，方便你记录"哪道题考倒了哪个模型"。也可以拿去考朋友、考学生、考面试者——反正题是无限的。

Each question comes with a random 6-digit instance ID, handy for tracking "which question stumped which model". Use them on friends, students, or interview candidates too — the supply is endless.

## 题型 / Question types（5 种 / 5 types）

- **真话假话 / Truth-tellers & liars**：谁在说真话？人物和真假话分布全随机。/ Who's telling the truth? People and truth/lie assignments fully randomized.
- **条件推理 / Conditional reasoning**："如果 A 则 B"类规则推演，条件随机组合。/ "If A then B" style deduction with randomized conditions.
- **排名推理 / Ranking puzzles**：根据若干条线索排出名次。/ Rank everyone from a set of clues.
- **数列推理 / Number sequences**：找规律填下一个数，答案由程序自动计算。/ Find the pattern; answers computed automatically.
- **随机类别 / Surprise me**：上面四种里随机抽一种，适合"盲测"。/ Random pick from the four above — perfect for blind tests.

难度：简单 / 中等 / 困难。人物越多、条件越绕、数列越坑。
Difficulty: Easy / Medium / Hard. More people, twistier conditions, trickier sequences.

> 问：谁说了真话？

> *Among A, B, and C, exactly one person told the truth.*
> *A said: "B is lying." B said: "C is lying." C said: "A and B are both lying."*
> *Who told the truth?*

## 诚实声明 / Honest notes

- 本站**不调用任何 AI**。题目由浏览器本地 JavaScript 生成，不联网、不花钱、不需要 API Key，断网也能出题。
  *This site calls **no AI**. Questions are generated by local JavaScript in your browser — no network, no cost, no API key. It works offline.*
- 数学上无法"绝对证明"AI 没见过**题型**，但随机参数保证**具体题目实例**无法靠背诵固定答案完成。
  *We can't mathematically prove an AI has never seen the **question type**, but randomized parameters make it impossible to solve a **specific instance** by reciting a memorized answer.*
- 推理能力强的模型**应该**能做对很多题——那恰恰证明它是真推理。这才是公平的测试，而不是为了难倒谁。
  *A model with strong reasoning **should** solve many of these — which proves genuine reasoning. That's a fair test, not a gotcha.*

## 技术实现 / How it's built

- `index.html`：单文件、零依赖、纯前端；逻辑题用穷举法保证解的唯一性。
  *Single file, zero dependencies, pure frontend; logic puzzles are brute-force checked for unique solutions.*
- `worker.js`：Cloudflare Worker 访客计数器，数据存在 KV。
  *Cloudflare Worker visitor counter backed by KV.*
- 部署 / Hosting：Cloudflare Pages（直接上传）；统计 / Analytics：Cloudflare Web Analytics。
